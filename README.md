# Цифровой деканат будущего

Концепт для конкурса MGIMO×AI Challenge, **не официальный сервис МГИМО**.
Все люди и данные вымышлены.

## Запуск

1. Установить Node.js 22.9 или новее.
2. Скопировать `.env.example` в `.env` и вписать `SESSION_SECRET`. Для ИИ-помощника — ещё `GIGACHAT_AUTH_KEY` и `GIGACHAT_SCOPE`; без них кабинет работает, а помощник сообщает, что отключён.
3. Выполнить:

```
npm install
npm run seed
npm start
```

4. Открыть http://localhost:3000

Тестовые логины и пароли выводит `npm run seed`.
