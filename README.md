# Цифровой деканат будущего

> **Концепт для конкурса MGIMO×AI Challenge (номинация «Вайб-кодинг»), не официальный сервис МГИМО.**
> Все люди, оценки, номера документов и преподаватели вымышлены. Официальный логотип вуза не используется.

Личный кабинет студента, где всё нужное собрано в одном месте: расписание с переносами и заменами,
успеваемость с понятной сводкой «как у меня дела», заявки на справки со статусами, уведомления деканата
и кабинет сотрудника, который обрабатывает заявки. Работает в браузере и с телефона, в том числе как
приложение без интернета.

## Запуск локально

Нужен Node.js 22.9 или новее.

```bash
npm install
cp .env.example .env     # затем откройте .env и впишите SESSION_SECRET
npm run seed             # создаёт базу data/dekanat.db с вымышленными данными
npm start
```

Откройте http://localhost:3000.

- **`SESSION_SECRET`** — длинная случайная строка. Получить её можно так:
  `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`
- **ИИ-помощник «Спроси деканат»** работает на GigaChat. Для него в `.env` нужны `GIGACHAT_AUTH_KEY` и `GIGACHAT_SCOPE`
  (ключ берётся в личном кабинете GigaChat API). Без них кабинет работает полностью, а помощник сообщает, что отключён.
- Остальные настройки (порт, адрес для QR-кодов справок, путь к базе) описаны в `.env.example`.
- `npm run seed` каждый раз заполняет базу заново: изменения, сделанные в кабинете, при этом сбрасываются.

Файл `.env` и папка `data/` с базой в git не попадают (см. `.gitignore`).

## Стек

- **Сервер:** Node.js и Express 5.
- **База данных:** SQLite в одном файле, доступ через `better-sqlite3`. Все запросы с параметрами, без склейки строк.
- **Вход:** логин и пароль, пароли хранятся только как хеш `bcrypt`. Сессии `express-session`, cookie `httpOnly` и `sameSite`.
- **Фронтенд:** HTML, CSS и обычный JavaScript, без фреймворков. Цвета и отступы — CSS-переменные в одном файле.
- **QR-коды:** библиотека `qrcode`. Больше зависимостей нет.
- **ИИ:** GigaChat, подключение написано на встроенном модуле Node.
- **Шрифты:** Playfair Display, Manrope и Inter, все со свободной лицензией. Файлы лицензий лежат в `public/fonts`.

## Что умеет

**Для студента**
- **Главная:** обложка с небом по времени суток и строкой дня («Сейчас идёт ТМО, ещё 40 мин»), текущая или следующая пара крупно, рейтинг, ближайший дедлайн, последняя заявка, уведомления.
- **Расписание:** «Сегодня» — таймлайн дня с линией «сейчас». «Неделя» — сетка как в календаре. Переносы, замены и смена аудитории выделены значками и подписями («ауд. 408 вместо 312»). Пары можно выгрузить в календарь телефона (`.ics`).
- **Оценки:** «Набрано на сегодня» вместо пугающего рейтинга, сводка «как у меня дела», сессия и долги, калькулятор «Что нужно на экзамене».
- **Надбавка:** активности, за которые дают баллы к рейтингу, запись на них и путь «заявка → подтверждено → баллы начислены».
- **Заявки и справки:** заказ онлайн, статусы «Принята → В работе → Готова», переписка с деканатом. Электронная справка с QR-кодом, который проверяется на открытой странице.
- **Цифровой студенческий билет** с QR-кодом, гильоширной сеткой и голограммой. Открывается на весь экран и без интернета.
- **Запись на приём в деканат:** тема, день и свободное время.
- **Уведомления:** объявления деканата, напоминания о сроках, изменения в расписании.
- **«Спроси деканат»:** ИИ-помощник отвечает по данным самого студента и по базе готовых ответов. Чужие данные получить нельзя по устройству сервера, а не по обещанию модели.

**Для сотрудника деканата**
- Заявки всех студентов с фильтрами, смена статуса, ответы, отказ с причиной, место выдачи бумажной справки.
- Объявления для групп и факультетов, подтверждение участия в активностях и начисление баллов, приём студентов.

**Везде**
- **Телефон с экраном от 360 px:** нижнее меню, всё нужное за 1–2 касания.
- **Приложение (PWA):** можно установить, без интернета открываются неделя и студенческий билет.
- **Русский и английский** интерфейс, светлая и тёмная темы.
- **Оформление «университетский журнал»:**
  - золотые линейки и штрихи под крупными числами;
  - перелистывание при переходе между страницами;
  - золотое конфетти, когда справка готова, баллы начислены или вы записались на приём.
- **Тур для новых студентов и жюри:** шесть подсказок поверх интерфейса, повторить можно из Профиля.
- **Доступность:**
  - работа с клавиатуры и экранным диктором;
  - контраст текста не ниже нормы;
  - учитывается системная настройка «Уменьшить движение».

## Безопасность

- Каждый запрос к данным проверяет права на сервере. Студент не увидит чужой профиль, оценки или заявку, даже подставив другой номер в адрес.
- Все данные пользователя выводятся с экранированием, это защита от внедрения скриптов.
- Секреты хранятся только в `.env`, в код и в браузер они не попадают.
