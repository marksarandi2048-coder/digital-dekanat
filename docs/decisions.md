# Ключевые решения

## 2026-11-04 — Основа проекта

- **Сервер — Node.js + Express 5, база — SQLite (better-sqlite3).** Один файл
  базы в `data/`, не нужен отдельный сервер БД — проект запускается двумя
  командами.
- **Одна таблица `users` для студентов и сотрудников** с полем `role`
  (`student` / `staff`). У студента заполнены направление, курс и группа,
  у сотрудника — должность. Так проще проверять права в одном месте.
- **Пароли — только хеш bcrypt.** При входе с несуществующим логином пароль
  всё равно сверяется с «пустым» хешем, чтобы по времени ответа нельзя было
  узнать, есть ли такой логин. Не больше 10 неудачных попыток с одного
  адреса за 15 минут.
- **Сессии — express-session**, cookie `httpOnly`, `sameSite=lax`, живёт
  8 часов; при входе сессия создаётся заново. Пока сессии хранятся в памяти
  сервера: после перезапуска нужно войти снова (для прототипа это нормально).
- **Права проверяются на сервере** (`src/access.js`). Студент видит только
  свой профиль; сотрудник деканата — профили студентов. На чужой и на
  несуществующий id студент получает одинаковый ответ «Нет доступа», чтобы
  нельзя было перебором узнать, какие id заняты.
- **Защита от внедрения скриптов:** данные выводятся только через
  `textContent`, плюс заголовок Content-Security-Policy запрещает скрипты
  со сторонних сайтов и встроенные скрипты.
- **`.env` читается встроенной возможностью Node** (`--env-file-if-exists`),
  без отдельной библиотеки dotenv.
- **Шрифты — системные**, без загрузки извне: нет вопросов с лицензиями,
  страница открывается быстрее. Логотип — собственный (щит с книгой).

## 2026-11-04 — Расписание

- **Каждое занятие хранится отдельной строкой с конкретной датой**, а не
  шаблоном «каждый вторник». Так перенос, замену или отмену легко показать:
  у занятия меняется статус, а старые значения (дата, пара, аудитория,
  преподаватель) сохраняются рядом в полях `old_*`.
- **Время — по номеру пары.** В базе хранится номер пары (1–7), а время
  звонков задано в одном месте — `src/pairs.js`: пары по 90 минут,
  большой перерыв после 2-й пары.
- **Отдельные таблицы дисциплин и преподавателей** — их же будем
  использовать в разделе «Успеваемость».
- **Переносы пока только в данных `seed`** (по одному примеру каждого вида
  на текущей неделе для каждой группы). Кабинет сотрудника для правки
  расписания — позже, если останется время: в обязательном ядре от
  сотрудника требуется работа с заявками.
- **Студент видит только расписание своей группы**: группа берётся из его
  профиля на сервере, параметр `?group=` в адресе для студента
  игнорируется. Сотрудник может выбрать любую группу.
- **Перенесённое занятие видно в двух местах**: на новом месте — цветной
  карточкой «Перенесено, было: …», на старом — пунктирной «Перенесено
  на …», чтобы студент не потерял пару.
- **«Сегодня» считается по московскому времени**, независимо от часового
  пояса сервера.
- **Изменения выделяются не только цветом, но и подписью** («Отменено»,
  «Другая аудитория») — понятно и людям, которые плохо различают цвета.
